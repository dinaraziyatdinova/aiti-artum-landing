# Айти_АртУм — ИТ-квесты для школьников

Готовый статический лендинг на HTML, CSS и Vanilla JavaScript. Сборка и установка зависимостей не нужны. Все изображения, SVG-иконки и кириллические шрифты находятся локально.

## Файлы

- index.html — все восемь секций, тексты, SVG-иконки Lucide, метаданные и форма.
- css/style.css — фирменные цвета, локальные шрифты, адаптивная сетка, состояния и анимации.
- js/main.js — настройки отправки, меню, выбор формата, lightbox, валидация и обработка формы.
- assets/images/owl-original.png — предоставленная оригинальная сова, скопированная без изменений; также используется как favicon.
- assets/images/ — оригинальные фотографии и видео организаторов; файлы сохранены без изменений.
- assets/images/optimized/ — адаптивные WebP-копии фотографий и обложка видео.
- MEDIA-REPORT.md — перечень материалов, размещение, причины отбора и результаты проверки.
- assets/images/placeholder-*.svg — прежние иллюстрации, больше не используются на странице.
- assets/fonts/didact-gothic-regular.ttf — официальный Didact Gothic Regular с кириллицей, локально для основного текста, интерфейса и текстовой части логотипа в шапке и футере; лицензия OFL-Didact-Gothic.txt.
- assets/fonts/manrope-variable.ttf — официальный Manrope Variable (200–800), локально для заголовков H1–H3 с насыщенностью 700; лицензия OFL-Manrope.txt. Прежние файлы Montserrat сохранены.
- assets/LUCIDE-LICENSE.txt — лицензия встроенных иконок.

## Как открыть

Откройте папку проекта в VS Code. Через расширение Live Server выберите для index.html команду Open with Live Server. Страница также открывается двойным кликом по index.html, но проверять интеграцию отправки нужно через HTTP/HTTPS.

## Фотографии и отзывы

На странице уже размещены восемь фотографий и одно видео, предоставленные организаторами. Первый экран использует новый снимок преподавателя со школьниками у компьютера: assets/images/hero-computer-class-original.png и адаптивные WebP-копии hero-computer-class-640/1280.webp. Точное распределение и имена исходников приведены в [MEDIA-REPORT.md](MEDIA-REPORT.md). Оригиналы находятся в assets/images/, облегчённые WebP-копии — в assets/images/optimized/.

Для замены фотографии обновите src, srcset, sizes, alt и реальные width/height в index.html. В галерее также обновите data-caption и data-full на кнопке: последняя ссылка открывает крупную версию в lightbox. Фотография первого экрана загружается приоритетно, остальные — лениво. Сохраняйте исходные пропорции при экспорте; положение кадра задаётся в css/style.css.

В lightbox доступны циклическое листание стрелками, клавишами ←/→ и горизонтальным свайпом. Счётчик и подпись обновляются; Escape, крестик и нажатие на фон закрывают просмотр с возвратом фокуса к исходной фотографии. Порядок слайдов соответствует фотокнопкам [data-gallery] в HTML; видео не входит в список. Крупные версии заранее не загружаются, после открытия предзагружаются только соседние кадры.

Видео находится внутри секции id="gallery". Заменяйте source data-src, poster и width/height вместе. Сейчас используется вертикальный оригинал 720 × 1280, элементы управления включены, автоматического запуска нет, preload="metadata". Источник подключается при приближении к плееру; без JavaScript есть ссылка на оригинальный MP4. Не помещайте тяжёлое видео в фон первого экрана.

Под галереей оставлен HTML-комментарий для будущих реальных отзывов. Вымышленных отзывов на сайте нет.

## Логотип

В шапке, первом экране, футере и favicon используется один исходник assets/images/owl-original.png. Его форма, цвета и пропорции не изменены. Для замены положите новый оригинал по этому пути или обновите соответствующие src/href в index.html. Надпись Айти_АртУм рядом с совой набрана текстом. Текущий исходник имеет прозрачные поля: при замене на файл с другой компоновкой проверьте размеры .brand-owl img и .hero-owl в css/style.css. Не используйте растяжение или обрезку совы.

## Подключение заявок

Сейчас форма НЕ отправляет заявки. Она проверяет поля, но после заполнения сообщает об отсутствии интеграции и предлагает телефон организатора. Без JavaScript кнопка отправки отключена. Данные не сохраняются в localStorage и не уходят в строку URL.

В самом начале js/main.js находится window.ARTUM_CONFIG:

- endpoint — публичный адрес обработчика; сейчас null.
- privacyUrl — путь к предоставленной организатором политике конфиденциальности; сейчас null.
- timeoutMs — время ожидания ответа (15000 мс).
- buildPayload — преобразование полей под выбранный сервис.
- isSuccess — проверка подтверждения успешного приёма заявки.

Для включения нужны ОБА адреса: endpoint и privacyUrl. Например, после создания обработчика и добавления утверждённого документа задайте endpoint: '/api/application', privacyUrl: 'privacy.pdf'. Это примеры локальных путей; сами файлы/обработчик не созданы. Пока политики нет, ссылка в согласии открывает честное пояснение, а не выдуманный юридический текст. После настройки ссылка ведёт на документ; дополнительная ссылка появляется в футере.

По умолчанию выполняется POST с Content-Type: application/json. Поля: name, phone (нормализованный +7...), format (Квест или ИТ-ёлка), group, message, consent (true). Обработчик должен вернуть HTTP 2xx и JSON {"success": true}. Один HTTP 200 без подтверждения не считается успехом.

Для Formspree или другого сервиса адаптируйте buildPayload/isSuccess и при необходимости формат запроса по документации сервиса. Для Telegram нужен серверный/serverless-обработчик, который передаёт заявку боту; секретный токен нельзя помещать в JavaScript или репозиторий. Настройте серверную проверку данных, ограничение частоты обращений и разрешённый origin, если обработчик расположен на другом домене. GitHub Pages размещает только статическую часть: обработчик размещается отдельно.

Кнопка блокируется во время запроса. При ошибке/таймауте введённые значения остаются в полях. При таймауте предлагается уточнить получение по телефону, поскольку сервер мог принять запрос. Сбрасывать форму разрешено только после подтверждённого успеха.

## Публикация

Для обычного статического хостинга загрузите index.html и папки css, js, assets в публичный корень. Сохраняйте относительные пути и структуру папок. README.md публиковать не обязательно.

Для GitHub Pages добавьте файлы в репозиторий и включите публикацию корневой папки выбранной ветки. Для Vercel импортируйте репозиторий как статический проект: без сборки и установки зависимостей, каталог публикации — корень проекта. Серверные обработчики при необходимости настраиваются отдельно.

После получения реального домена замените og:image на абсолютный HTTPS-адрес изображения, добавьте og:url и canonical с адресом сайта. В проекте намеренно нет вымышленного домена. Перед рекламной кампанией добавьте утверждённую политику, подключите обработчик и проверьте получение одной реальной тестовой заявки организатором.

## Проверки

Проверено в Chrome: ширины 1440, 1024, 768, 430, 375 и 320 px; отсутствие горизонтального скролла; мобильное меню и Escape; якоря; выбор программы; ошибки обязательных полей и телефона; честное поведение без интеграции; lightbox и возврат фокуса; режим reduced motion; отключённый JavaScript.

На локальных перехваченных тестовых ответах проверены: загрузка, блокировка повторной отправки, нормализация телефона, подтверждённый успех, HTTP-ошибка, неподтверждённый ответ и таймаут с сохранением данных. Реальная доставка организатору не проверялась: интеграция отсутствует.
